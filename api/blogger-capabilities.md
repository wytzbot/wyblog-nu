# WyBlog Blogger API capability matrix

| Area | Blogger API v3 | WyBlog handling |
|---|---|---|
| Posts | Yes | Read/create/update/patch/publish/revert/delete |
| Pages | Yes | Read/create/update/delete |
| Comments | Yes | Read + supported moderation operations |
| Blog metadata | Yes | Read |
| Blog locale | Yes | Read |
| Pageviews | Yes | Read |
| Theme/template editing | Not exposed in v3 resource reference | Link to Blogger |
| Layout/layers | Not exposed in v3 resource reference | Link to Blogger |
| Full Blogger admin settings | Not exposed as a general v3 settings resource | Expose only API-supported data |
| Post HTML | Yes | Visual/HTML editor |
| Post labels | Yes | Editor SEO panel |

Source: Google Blogger API v3 reference.
